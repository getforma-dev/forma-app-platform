## Review questions answered

1. **Authorization.** Three independent checks: `precheck` (`authorization.rs:421-441`: active organization and membership at the request's epoch, live entitlement, `organization_permissions.admin_policy`), `fence` (`:615-628`: `lock_member_authority`, entitlement and permission re-read under the lock), and the definers (`0023:409-417`, `:452-460`: the `genui.organization_id`/`principal_id`/`membership_epoch` settings must equal the arguments, membership active at that epoch, `admin_policy` present). A guest has no `TrustedRequest` (`begin_shared` never makes a member permit), so it cannot reach them. `set_display_name` requires `genui.principal_id` = `p_principal` (`:365`) and no API takes a target. `admin_remove_member` revokes exactly the target's membership and active entitlements, bumps the epoch (sessions die at the next request: campaign `:577-592`), refuses self, last admin and non-members; the lock order (caller `FOR SHARE`, target `FOR UPDATE`) makes two admins removing each other serialize so an organization cannot end with zero admins (reasoned, not tested). The operator is not a principal and cannot be removed; an app owner can be, by design, and their works stay (`creator_revoked_at` untouched, matching the notice). The overview reads no `principals` column; no email is stored anywhere.
2. **Consent integrity.** A membership is created only in `admit_redemption`'s admitted branch, which inserts the consent and the `admission.consented` event in the same transaction (`:321-344`). The version flows form → `FlowKind::SignUp.notice_version` (`invite.rs:383`, `sessions.rs:487-516`) → `reserve_code` → presignup row → `record_pending_admission` copy (`:196-197`) → `admit_redemption` read under the row locks (`:242`); nothing client-controlled after the form. A NULL version refuses (M1 for the test). The page text equals the ADR word for word: I diffed the title and all six paragraphs of `notice.rs` against the `origin/main` blockquote (6/6 match); the SSR test asserts every paragraph and the version on the page. The form rule is exact on the decoded field list (`form_urlencoded`): either order, no duplicates, no extras, `consent` exactly `1`; `%31` decodes to `1`, which is the same consent. Unit test covers 10 refusals, the router test 16, the campaign proves no reservation, flow or PAR without consent.
3. **Migration.** Additive except the recorded drop (m1): nullable columns with CHECKs, one RLS table, broadened chain kinds, column-level grants to `genui_admit` only for what the definers read, EXECUTE closed to `genui_workspace`. `ALTER POLICY admission_chain` changes only `WITH CHECK` of the RESTRICTIVE INSERT policy (`0003:162`), as 0008 did. Catalog v23 passes `schema-pins` and the catalog check. `reserve_code` callers: all updated (Rust and Python); the Python operator never calls it.
4. **Name cache.** Keyed by (organization, principal); `label(OTHER, principal)` stays neutral (campaign `:408-412`, unit test). Refreshed on `set_display_name` and on admission (`sessions.rs:758`); startup fill per registry organization with retry in the sweep (`main.rs:64-76,374-379`). Demo organizations unchanged when no member name is set (member name wins over the DS-44 persona, which is right).
5. **Six decisions.** (1) `genui_admit` ownership: **confirm**; the role's grant set widens (`sessions.last_seen_at`, `audit_events` metadata, `memberships.status` and `entitlements.status` UPDATE) and the qualifier pins it exactly; a separate role is not worth the scaffolding for release B, record as D7.1 debt (the header does). (2) Consent on the presignup row, then copied: **confirm**; it binds the version to the row the consented form created. (3) actor = admin, digest = target: **confirm**, with m2. (4) `last_admin` for a sole admin removing itself: **confirm**. (5) `last_active` = max(audit event, session touch): **confirm**; it is what the notice promises; touches are recorded at most once per minute (`sessions.rs:871,895`). (6) Tenant-foundation step: **confirm**; CI must run the campaign (about 15 s).
6. **Tests.** The campaigns use real rows for every refusal (non-admin, cross-organization admin, outsider, removed admin, stale epoch, revoked target, stranger, malformed id) and assert footprints unchanged; the removal check mints a real session and watches it die. Break-and-restore proofs: none recorded (M2).
