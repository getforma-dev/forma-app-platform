# Evidence

## What this is

Measured results for tickets, one directory per `APP-NNN`. Markdown indexes are readable. Raw `*.json` and `*.log` files are search noise.

## Authoritative sources

The ticket that links the directory. A file here records what ran. It does not by itself move a ticket to Done.

## Verify a change here

Do not change evidence as part of a docs edit. `just check board` checks links that point here.

## Never

Do not edit, rename or delete files here. Do not rewrite a receipt to match a later result. Do not search this tree for current guidance. Open a path from a ticket or an ADR.
