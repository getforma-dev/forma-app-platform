## Headline findings (details and citations in §§2–5)

1. **Critical path:** 13 of 17 PH02 tickets are strictly serial — `APP-015 (or APP-016) → 017 → 018 → 020 → 021 → 022 → 023 → 025 → 027 → 028 → 029 → 030 → 031` (12 × L, 1 × M). Its head waits on PH1 Tasks 5 and 7 (APP-073, APP-009); APP-020/023/030 also wait on PH1 Tasks 9–11 (APP-012/013/014). Splitting APP-027 (geometry vs linked views) would cut the chain to about 10 (§2).
2. **The parser cannot drop into the app binary as-is:** Wasmtime 36.0.19 requires Rust 1.86 against the app's 1.85 floor, the spike's exact serde/serde_json/sha2 pins conflict with the app's (§5.3 #14), and the qualified WASM digest is not reproducible across hosts — APP-011's first Linux CI run failed its parser-digest check (`fixtures/qualify.py:48-50`; D9.1).
3. **The beta task budget contradicts the platform slot numbers:** the 2 vCPU/8 GiB task holds one 2 GiB parser and two 1 GiB DuckDB operations (demo design:528) versus three import slots and eight query slots per node in the platform design; with two query slots per organization one organization can occupy both task slots, yet APP-024 must prove another organization keeps making progress (§5.3 #2–3).
4. **A new contract edition is unavoidable:** no cancelled job state, no source coverage, `operator_version`/`renderer_version` fixed at 1 in the contract and the database, `exact_rational` with no rational type, no window-duration denominator, and `partial` fixed to `false` while the UI must show a partial state (§5.3, D9.6).
5. **Authority paths are missing for PH02 writers:** the worker role has no grants or recheck path, no application path writes creator permissions for a new source or new work (ADR-007:38; ADR-004:34), there is no `worker` audit chain, and the granted `query_receipts` table is never created (§5.1 #8–11).
6. **Storage decisions are open:** Parquet writer, layout and digest determinism; design vs ADR-007 object key layout; an upload route (up to 10–100 MiB) that D7.14's 4 KiB/64 KiB body limits do not cover; orphaned objects the tenant role cannot delete (§5.1 #1–4, §5.3 #1).
7. **Canvas budget:** the measured route has 162 B of headroom to the 28,100 B target and APP-003 has no pan/zoom/move/resize code; the donor is 2,467 lines of core-2.x DOM code (§3.14, §4.7).
8. **Deleted sources:** today's work precheck turns any deleted dependency into a uniform 404 for the whole work, while APP-016/S06 require reopening with the tombstone (§5.3 #9).

### 3.2 CSV/XLSX literal and interpretation rules

### 3.8 Stale-response rejection and revocation timing

- Linked filters: "a filter change increments the epoch, sends one typed query a linked view with it, and drops any response whose epoch is behind (R7; C06); the canvas polls the membership epoch every 5 s, one read, and re-queries only on a filter change or an epoch bump" (design:333). Late page: "the island discards any page whose receipt carries an epoch below the current one … The same discard drops a late Finance response in Security (S05)" (design:410). Queued revocation: "At execution and again before release P4 re-reads … membership … and returns denied" (design:411).
- R1 "a context switch discards late results" (design:113); C03 "Switching context cancels or discards late results for the previous organization/work; unsaved work is saved or clearly retained for user recovery before leaving" (`SHARED-CONTRACTS.md:31`); S06 row "Context switch during a delayed response | Drop mismatched context/filter response" (`SCENARIOS.md:94`); "Late Finance responses cannot populate Security cards" (`SCENARIOS.md:82`).
- **Revocation budget overrides design's 5 s poll:** total 5,000 ms = poll ≤2,000 ms + request deadline ≤2,000 ms + clearing ≤1,000 ms; freshness measured from request start; an overdue/stale/out-of-order response cannot extend authority (ADR-002:25-27). Measurement owned by APP-049/054 (ADR-002:29).
- Filters in requests: "filters travel in bodies, not query strings, because the edge logs URLs" (design:786).
