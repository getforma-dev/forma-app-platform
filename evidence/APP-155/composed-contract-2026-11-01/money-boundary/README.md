# Money input boundary regression

CI caught a real production regression: an action for $86.00 displayed $8,600.00 because the shared scalar constructor converted an already normalized minor-unit string a second time. The failing amount assertion was retained.

The repair limits human decimal conversion to HTML form parsing and names the browser helper for that form-only purpose. Internal action values and typed JSON commands retain their integer minor-unit representation. A focused regression exercises action parsing and display, native form parsing, and JSON parsing against the same 8600 value.

The real PostgreSQL actions campaign now passes all 14 existing checks, including the original $86.00 assertion, confirmed commit, idempotency recovery, sharing and tenant restrictions. Focused Rust command tests pass 25/25; browser money and retry unit tests pass 7/7; TypeScript checking passes. This packet is local synthetic qualification, not a hosted or real-model run. The retained source and private-log hashes bind the observations without publishing runtime logs or confirmation tokens.
