# Evidence

Preparation evidence belongs here. Future tickets should store compact reproducible reports under `evidence/APP-NNN/` and link the report from the ticket log. Keep meaningful failures alongside successful results. Logs containing credentials, real source rows or personal information do not belong in Git.

The [design manifest](../design/snapshot-manifest.json) verifies copied source bytes. [Upstream snapshots](../Tickets/evidence/upstream/README.md) preserve the existing dependency tickets. Neither proves application implementation.

The latest [workspace-entry AWS release](APP-162/aws-workspace-entry-2026-11-02/README.md) records source `7c3ab12`, exact-candidate qualification, preserved trial, independent runtime audit and actual browser handoff/switch behavior. It does not claim a new credential login or completed guest signup.
