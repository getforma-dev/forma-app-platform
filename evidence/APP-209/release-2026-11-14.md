## The expiry moved

The stop moved from 2026-12-15T14:00Z (after release B) to **2026-12-14T20:00Z**: the promotion subtracts the 18-hour default from the canonical `2026-12-16T08:00Z` on every release ([ADR-019](../../docs/architecture/ADR-019-MAIN-TRUNK-AND-RESERVATION-CAP.md)). `expiry_renewal` changes only the canonical input, so it takes effect only through a later release. The purge (runbook section 10) must therefore finish before 2026-12-14 20:00 UTC unless a later release renews the stop. The runbook, the readiness calendar, the class guide, ADR-008 and the release record were corrected in this close-out.
