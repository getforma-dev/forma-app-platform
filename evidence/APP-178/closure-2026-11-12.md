## Note for Victor

A temporary organization suspension permanently removes a guest's canvas link (audited). After restoring the organization, the guest must Add the app again. This matches the existing rule that re-enabling placement needs a new Add (APP-154), but it is a product choice you may want to revisit.

## Limits

- The campaign uses synthetic verified identities and the native PostgreSQL fixture. It makes no hosted or AWS claim.
- "Reveals nothing" is shown as an identical refusal for an expired key and an unknown key, at the store level. The HTTP layer maps both to the uniform 404, per APP-154.
