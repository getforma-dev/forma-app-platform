# CSS watch correction — 2026-11-01

The installed `@getforma/build` 3.2.0 watch process builds the configured CSS entries on startup. Editing a standalone stylesheet does not reliably rebuild those entries through its JavaScript watch graph. This left a prior page check using stale CSS despite a TypeScript rebuild.

The app-local `app/admin/package.json` dev command now uses the already installed tsx watcher:

```sh
tsx watch --include 'src/**/*.css' build.ts --ssr --watch --strict
```

The CSS include restarts the full build, retaining strict native SSR and the existing Forma JavaScript watcher. No dependency, lockfile, generated asset, or framework source was manually changed.

## Verification

Ran `npm --prefix app/admin run dev` in the isolated audit checkout, without starting an application server. After the initial build, appended one unique CSS declaration to `src/styles/canvas.css`, then waited for both its emitted CSS and the manifest fingerprint to change. Restored the original source bytes and waited for the declaration to disappear from emitted CSS and the manifest to change again. Stopped the watcher afterward.
