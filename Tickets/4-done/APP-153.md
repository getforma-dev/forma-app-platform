## Why

The right-hand pane is titled like a library, and it also holds Commands, Ask, and Shortcuts. Victor wants to know why those four share one pane, and whether that is where each of them should stay. APP-143 will attach Ask to the thing the member clicked. That work should not assume Ask remains a tab beside the card list.

## What exists today

One aside, `#cv-library`, is the right pane (`app/admin/src/canvas/app.tsx`). Its tab list is exactly four buttons:

- **Library.** The admitted apps and cards the member may place. Search, drag onto the canvas, Add, and Remove. The L key opens this tab.
- **Commands.** Every slash command, with arguments and examples. `/commands` and `/help` open it. Clicking a command puts it in the intent bar. It does not run the command by itself.
- **Ask.** The question form. `?` as the first character in the bar opens this tab (APP-122). The question goes to `POST /v1/ask`. Shape is not this tab. Shape is `/shape`.
- **Shortcuts.** Every action with its click path and its keys (APP-112). `/shortcuts` and the menu item "Shortcuts and commands" open it. It used to be a separate sheet. A line at the top links to the Commands tab.

The four were gathered into one pane so the old shortcuts sheet, the command list, and Ask would not each be their own modal. The current aria label is "Library, commands, Ask and shortcuts"; APP-143 corrected the earlier omission of Ask separately from this documentation spike.

## What changes

Write `docs/planning/app-model/library-pane.md`. Read `app.tsx` for the four tabs, `shortcut-tab.ts`, `slash.ts` for `/commands`, and `ask.ts` for `openAsk`. No product code.

The note answers:

1. What each tab does, in one paragraph, from the file that fills it.
2. Why they share a pane. The reason is the one in those files, or "not written down" if the file does not say.
3. For each tab, whether it should stay in this pane. Library is the one that places cards. Commands, Ask, and Shortcuts may belong in the intent bar, on the app page, or behind the menu. The note picks stay or move for each, and says what would break if it moved.
4. What APP-143 should assume. If Ask should leave the pane, the note says so. APP-143 does not move it until this note is accepted.
