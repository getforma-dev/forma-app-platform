## Why

A displayed number must be exact, bounded and traceable to the authorized evidence and record snapshot that produced it. This ticket delivers: deliver a minimal authorized query with receipt.

## What changes

Exact fixture source/query version, parameters, actor/policy epoch, record snapshot and result digest; current membership and entitlement authorization before engine admission, at execution and delivery; display receipt and distinct error/denied state in native view.

Keep this a reviewable slice: L means approximately 3–5 focused days. Re-estimate before selection and split the ticket if it exceeds five focused days. The estimate is a planning bound, not a delivery date.

Scope excludes production deployment and real customer data; this is a synthetic qualification. Upstream framework/auth changes remain with the FormaStack team.

## Acceptance tests

- [x] An authenticated permitted principal runs the minimal typed query and receives an exact result with app/source/operator/parameter/policy/record-snapshot identities and result digest.
- [x] The same query with foreign or revoked scope is denied before release, including when authorization changes between execution and delivery.
- [x] The native view exposes the supporting receipt and distinguishes loading, empty, failed and denied outcomes; an execution failure never displays a fabricated zero.

The actual-public-beta-API acceptance item (anonymous, pre-access-only, expired/revoked-entitlement and foreign-tenant requests invoke no engine and disclose nothing; revocation while queued denies delivery; dispatch counters and both race orders) moved verbatim to [APP-076](../0-backlog/APP-076.md) by [ADR-005](../../docs/architecture/ADR-005-PHASE-1-SEQUENCING.md). The admission gate is still consumed here: execution and delivery are admitted only through APP-009 sessions and APP-073 current entitlement on the local harness.
