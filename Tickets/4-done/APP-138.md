## Why

The app's blue system-font interface is visually unrelated to the Forma site. The suite needs a common identity and a clearer working interface.

## What changes

Use getforma.dev's Space Grotesk, paper/ink/lime palette and geometric F; distinguish the product with a Canvas label. Redesign the welcome layout, header, command bar, library, cards and native entry pages. Preserve canvas geometry, actions, receipts and authorization.

## Acceptance tests

- [x] Shared brand, self-hosted font, light and dark surfaces across the app.
- [x] Welcome choices, library, command bar and populated cards remain usable.
- [x] Desktop and narrow viewport layouts, visible keyboard focus and reduced motion checked in browser.
- [x] Strict native build, admin tests and required repository checks pass.
- [x] Independent review of the concrete change recorded.

## Verification

`just check`, `npm --prefix app/admin test`, browser inspection of light/dark welcome and populated canvases, library and native entry pages. No cloud mutation.

## Migration and rollback

No schema or authority change. Revert the presentation changes to restore the prior interface. Existing data and saved canvas geometry are preserved.
