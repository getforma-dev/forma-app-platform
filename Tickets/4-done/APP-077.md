## Why

The production image omits `tenant_seed.py`, the contract validator, fixtures and their dependencies, so the managed seed in the [managed plan](../../evidence/APP-008/managed-plan.md) has no runnable artifact. The package must exist and be reviewed locally before APP-078 reserves a window. The two-process race coordinator that proves real lock waits on RDS moved to APP-080 by [ADR-008](../../docs/architecture/ADR-008-YC-DEMO-AND-BETA-MVP.md). The beta still proves the race behavior: APP-014 on the local harness and APP-076 through the public API; what is deferred is the RDS lock-observation proof, which GenUI requires before any real organization.

## What changes

Build a separate operator image and package for the migration identity (`PGPASSWORD` from the execution secret, no application role-assumption grants) with subcommands `migrate` (canonical `apply_migrations` for every landed migration), `verify-catalog`, `seed` (`tenant_seed.seed` with validated envelopes), `admission {issue,list,revoke,extend}` (APP-073's operator command, raw code printed exactly once) and `upload-sources` (fixture source bytes normalized through the reviewed APP-004/005 adapter and written under `o/<org>/sources/<source_id>/<revision_id>` with KMS, recording the real digests). Every ECS override fits 8,192 bytes with a matching `entryPoint`. Add the optional count-zero `OperatorTask` definition to the CDK stack with tests.

- [x] The optional `OperatorTask` definition (migration execution role, `PGPASSWORD` secret, count zero) passes the CDK template tests; the service and qualification task definitions are unchanged.
