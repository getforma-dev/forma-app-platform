## Why

The platform needs a usable spatial workspace and an equivalent accessible path over the same saved work. This ticket delivers: qualify a 3.2 native canvas with the full required primitive library.

## What changes

Measure actual route cost, typed props size, first render, adoption/node identity, event interaction, numeric SVG and keyboard path; prove no runtime-generated code/markup or silent Browser fallback.

Keep this a reviewable slice: M means approximately 1–3 focused days. Re-estimate before selection and split the ticket if it exceeds five focused days. The estimate is a planning bound, not a delivery date.

Scope excludes production deployment and real customer data; this is a synthetic qualification. Upstream framework/auth changes remain with the FormaStack team.

## Acceptance tests

- [x] Build and render a representative native canvas including every launch primitive on published 3.2; record route gzip, typed-props size, render throughput and peak memory using the actual build report.
- [x] Observe server-rendered node identity through island activation and interact with a form, linked filter, keyboard focus and numeric SVG without remounting or silent Browser fallback.
- [x] Attach FORMA-246 conformance evidence and FORMA-232 budget disposition; an exceeded shipped cap blocks integration unless a released upstream change satisfies it.
