## Why

Continuing shared work and starting independent work require separate grants, current source access and explicit data audiences. This ticket delivers: deliver and measure revocation end to end.

## What changes

Membership/grant/policy epoch, active display invalidation and context cancellation, execution-and-delivery checks on queued query/export/outcome; two race order tests on commands/adoption; meet clarified <=5 s healthy-connectivity target.

Keep this a reviewable slice: L means approximately 3–5 focused days. Re-estimate before selection and split the ticket if it exceeds five focused days. The estimate is a planning bound, not a delivery date.

Scope excludes production deployment and real customer data; this is a synthetic qualification. Upstream framework/auth changes remain with the FormaStack team.

## Acceptance tests

- [ ] Membership, policy and grant revocation stops new server results unconditionally and invalidates already open displays within the clarified total <=5-second healthy-connectivity target.
- [ ] Revoke during a queued query/export/outcome response and confirm authorization is rechecked at execution and immediately before release, including cached results.
- [ ] Exercise both orderings of paused new command versus revocation/adoption: a stale command cannot commit after the authoritative change, while an earlier authorized commit remains in history.
