## Why

The panel will watch Victor's recording, then open the live site and do their own workflow. That site cannot be the sandbox. Diego, Sarah, Priya, and the seeded library are for local testing. A copy of that world must not be what AWS serves. Victor also needs one local port that is empty and is the same kind of world as the deployment, so the recording and the link he shares are the same product.

## What changes

Keep the pitch profile as the sandbox. On the main checkout that is `127.0.0.1:4001`, `4002`, and `4003`. Do not delete it. Do not deploy it. Do not point the trial link at it.

Pin the main checkout's clean profile, `127.0.0.1:4010`, as the local twin of the AWS trial. A newly reset clean instance has no library apps, no placed cards, and demo mode off. Worktree clean ports are disposable copies and are not this twin. Emptying `4010` before the demo is an operator step on the main checkout (`just dev clean reset`). This ticket does not run that reset, and it does not drop the pitch database.
