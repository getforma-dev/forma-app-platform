## Why

The Shortcuts tab is a hand-written `SHORTCUTS` table (`app/admin/src/canvas/shortcut-tab.ts:23-75`) that no longer matches `main`:
- some rows tell members to place loose cards, which ADR-018 removed;
- some refer to an Ask tab, which moved to the attached assistant (`98706e4`).
`docs/pitch/GUIDE.md` and `SCENARIOS.md` repeat some of this. It also reads the command registry only for `GRAMMAR`, so "one registry is the only source" (APP-118) holds for two of three surfaces. Separately, no test shows that a teammate's `/v1/notes` lists only their own notes (APP-109).

## What changes

1. Correct the stale Shortcuts rows. Prefer deriving them from the command registry where the action is a command.
2. Correct the GUIDE and SCENARIOS passages that teach loose-card placement or the old Ask tab, with a dated note rather than silent rewriting of history.
3. Add a test that a second member's `/v1/notes` returns only that member's notes, and that the author's notes work is the uniform 404 to them.

## Acceptance tests

- [ ] Every Shortcuts row describes behavior that exists on `main`, and a test fails if a row names a removed action.
- [ ] GUIDE.md and SCENARIOS.md teach the whole-app Card, Stack and Open views and the attached assistant, with the change dated.
- [ ] A teammate's `/v1/notes` lists only their own notes, and the author's notes work is the uniform 404 to them.

## Verification

Admin tests (`npm --prefix app/admin test`), a notes test in the actions or pitch campaign, and Victor's browser look at the Shortcuts tab.

## Migration and rollback

Text and test only. Rolling back restores the old text.
