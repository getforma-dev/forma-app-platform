## Why

The model may propose useful supported definitions but cannot expand authority, silently disclose evidence or become a runtime dependency. This ticket delivers: build private compatible catalog retrieval.

## What changes

Metadata-only per-org index, local embeddings, lifecycle rebuild, authorized candidate filtering before ranking plus fresh compatibility check; stale hit cannot grant access, foreign title cannot leak.

Keep this a reviewable slice: L means approximately 3–5 focused days. Re-estimate before selection and split the ticket if it exceeds five focused days. The estimate is a planning bound, not a delivery date.

Scope excludes production deployment and real customer data; this is a synthetic qualification. Upstream framework/auth changes remain with the FormaStack team.

## Acceptance tests

- [ ] Each organization index contains only permitted catalog metadata/curated examples and is stored/loaded within that tenant scope.
- [ ] Search filters authorized candidates before ranking and rechecks discover/input compatibility on use; foreign titles and stale retired hits disclose no authority or private data.
- [ ] Publication/retirement triggers a bounded index refresh and missing index degrades to click/alias navigation without invoking a remote model.
