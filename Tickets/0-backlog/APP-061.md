## Why

The managed workflow must remain bounded, recoverable and auditable under real failure conditions before it handles customer data. This ticket delivers: enforce supply-chain and reversible deployment gates.

## What changes

SHA-pinned CI actions, lockfile/license checks, SBOM, keyless signed image/provenance, digest deployment; previous/current API fixtures, expand/contract migrations, upgrade/downgrade/upgrade and retained renderer/assets; callee-first canary rollback.

Keep this a reviewable slice: L means approximately 3–5 focused days. Re-estimate before selection and split the ticket if it exceeds five focused days. The estimate is a planning bound, not a delivery date.

Scope excludes unapproved paid provisioning or real-data processing; completing preparation does not itself authorize either. Upstream framework/auth changes remain with the FormaStack team.

## Acceptance tests

- [ ] Build from pinned lockfiles and SHA-pinned actions, produce license report/SBOM and keyless signed provenance/image, and reject unsigned or mismatched release digests.
- [ ] Run previous/current API and stored-definition compatibility fixtures plus expand/contract and upgrade/downgrade/upgrade rehearsal; retain required renderer versions and prior assets.
- [ ] Deploy callee-first through measured canary waves, with receipt mismatch/cross-tenant failure rolling back and current alert conditions blocking progression.

Prepare and exercise rollback on isolated synthetic state before live use. Retain backups, audit and deletion ledger; irreversible key deletion requires its explicit hold/confirmation process and cannot be undone by deployment rollback.
