## Why

The design requires one coherent versioned boundary so implementation does not confuse a released framework with an implemented platform. This ticket delivers: persist and admit a minimal typed definition and work binding.

## What changes

Immutable canonical digest, versioned registered kind/operator, correct input contracts (not author evidence IDs), separate published app/saved work; unknown/executable/excessive shapes rejected.

Keep this a reviewable slice: L means approximately 3–5 focused days. Re-estimate before selection and split the ticket if it exceeds five focused days. The estimate is a planning bound, not a delivery date.
