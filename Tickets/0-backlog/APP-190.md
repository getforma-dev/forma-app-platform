## Why

Outside demo organizations, every person shows as "Member 1a2b…" (DS-44 names are demo-only). Real people sharing, reviewing and administering need real names.

## What changes

Migration 0023 adds `memberships.display_name`, which the member sets, bounded and printable, through an audited narrow write. `directory::label` uses it for any organization, through a process-wide cache refreshed on admission and on change; the DS-44 file stays demo-only. The canvas asks for a name at first sign-in, and members can change it.

## Acceptance tests

- [ ] A member sets and changes their name, which appears in share lists, admin, records, Ask, MCP and Slack for that organization only.
- [ ] Invalid names (empty, too long, control characters) are refused. The write is audited, and another member can't set it.
- [ ] An independent review finds no blocker.

## Verification

Storage and route tests; the org-admin campaign; SSR tests.
