## Why

The model may propose useful supported definitions but cannot expand authority, silently disclose evidence or become a runtime dependency. This ticket delivers: enforce the five assistant tool boundaries.

## What changes

Compose/set parameters/query/explain/propose command only; query tool returns receipt ID/count rather than evidence, human explicitly submits every mutation, no publish/policy grants; injected cells/notes cannot expand tools.

Keep this a reviewable slice: L means approximately 3–5 focused days. Re-estimate before selection and split the ticket if it exceeds five focused days. The estimate is a planning bound, not a delivery date.

Scope excludes production deployment and real customer data; this is a synthetic qualification. Upstream framework/auth changes remain with the FormaStack team.

## Acceptance tests

- [ ] The assistant can invoke only compose, set parameters, query, explain and propose-command tools under server authority; no publish/policy tool exists.
- [ ] A query tool returns a receipt identifier/count instead of evidence rows, and every record mutation waits for explicit user submission.
- [ ] Injected instructions in cells/headers/notes attempt forbidden read/write/publish operations; capture the server denial and verify no effect or widened authority.
