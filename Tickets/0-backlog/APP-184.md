## Why

Only per-member hourly model limits exist, and they reset on every deploy. No daily, dollar or organization cap exists (APP-043 Backlog). Real shared use needs a hard daily ceiling that people understand when they reach it.

## What changes

One process-wide daily counter, reset at UTC midnight, checked where every Anthropic request is sent (`composer/model.rs`). Past the cap the call fails with `model_daily_cap`, which every model-backed route answers as 429 `daily_limit`. The canvas says the limit is reached and when it resets. The default is 1,000 calls a day, in code (Fable advisor: 400 is about six compositions per person on a class day). The message says building and Ask pause until 00:00 UTC while apps and entries keep working. `GENUI_MODEL_DAILY_CALLS` overrides it for tests, with no stack change.

## Acceptance tests

- [ ] Past the cap, no request reaches the provider, and every model-backed surface answers 429 `daily_limit` with the plain message. Tests fail with the check removed.
- [ ] The counter is shared by every model client in the process and resets at UTC midnight, shown with an injected clock.
- [ ] An independent review finds no blocker.
