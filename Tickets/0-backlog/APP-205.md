## Why

A form shows a `reference` field as a raw identifier box nobody can fill ([APP-193 finding](../../evidence/APP-193/finding-2026-11-14.md), G3), which is why the composer refuses reference fields today. Release C's entries point at items through references.

## What changes

In builder B3's files (`app/src/query/routes.rs`, `canvas.rs`, `page.rs`, `canvas_tests.rs`, `app/src/commands/mod.rs`, `app/src/main.rs` for the SSR form, `app/admin/src/work/render.ts`, `app/admin/src/canvas/render.ts`):
- `document_forms` fills, for each writable `reference` field whose `target_input` is bound in the work, choices from the work's listing (read under `own_rows`): value = record id, label = the record's first text field (at most 100 characters) or "Record", newest first by commit sequence, the current record preselected, at most 200; an unbound target or no readable record renders a disabled select with "Nothing to choose yet".
- `commands::FieldRow` carries value/label choices (today's `options` string holds values only); the canvas form, the record page form and the SSR form render them through the existing `has_choices` path; `typedFormValue` and `form_typed_value` already type the selection as `{"type": "reference", "input_id", "record_id"}`.
- Fields a command stamps with `set_now` are not writable and render read-only, as non-writable fields do.
- The confirmation and outcome copy for the two new 422 codes stays in `commands.ts` (APP-203); this ticket changes no HTTP shape.

## Acceptance tests

- [ ] A form for a schema with a reference to a bound records input shows a select of the readable target records labelled by their first text field, newest first, with the current record preselected, on the canvas form, the record page and the SSR form; submitting commits a typed reference that storage accepts (`just campaign canvas` extended).
- [ ] A contributor sees in the picker only the target records they may read (an `own` target lists their own rows; a shared target lists all), the owner sees all; an unbound target or an empty readable set renders the disabled "Nothing to choose yet"; a stamped (`set_now`) timestamp field renders read-only and is never posted.
- [ ] The admin bundle typechecks, its tests pass, and the existing `canvas`, `pitch` and `record-components` campaigns stay green; a Playwright smoke (one) records the picker on beta's clean profile.
