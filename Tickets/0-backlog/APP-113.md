## Why

Victor, 2026-10-30: "Make sure you also do comprehensive code review for dead code and code smells, any bugs that may appear." Four independent read-only reviews covered the pitch's changes since `9cf52c2`:
- server request paths;
- storage, SQL and runtime;
- canvas TypeScript;
- infra, scripts and contracts.

They found no XSS. All new tables have ENABLE+FORCE RLS keyed by organization, definer functions pin `search_path`, and no SQL is built from input. They also found the bugs below.

## What changes

The four fix branches below each fix every High and Medium finding in their area, remove the confirmed dead code, and make the low-risk smell fixes. Large refactors are deferred (listed at the end).

**Server (`fix/review-server`).**
1. A non-ASCII panic in `rehearsed::amount` and `workflows::phrase_after`, reachable from receipt uploads in every organization.
2. The `/v1/act` folder path runs before the rate limit, and the folder entry points skip `COMPOSE_MEMBER`/`EXPLAIN_MEMBER`.
3. The body is read before the session check in `/v1/act` and widgets customize.
4. Demo gating does not all go through `demo::is_demo_org` (`GENUI_DEMO_MODE` ignored).
5. An MCP draft spend race.
6. An `i128` money overflow in the ledger.
7. The MCP limit is per token, not per member.
8. MCP share skips the lineage step.
9. Orphaned objects on box upload failure.
10. A slug uniqueness race.
11. Unlimited row-creating routes.
12. An unbounded Slack notifier.
13. Slack drafts have no per-member cap.
14. Model replies are buffered before the size check.

Dead code: `ACT_DEADLINE`, `directory::all`, `demo::enabled`, test-only helpers compiled into the production binary, and `Body::Decide`'s unused `work`. Docs: "6 per hour" against 30, and DS-39's organization.

**Storage (`fix/review-storage`).**
1. The filer can decide their own record. Storage must require creator ≠ decider for transitions on existing records.
2. The expense `submit` can write `approved`; `initial` must be required for governed enums.
3. The CSV normalizer ordering bug (unsorted `time` is refused, null `time` crashes).
4. Box file grants are not tied to live `record_read`.
5. Count-then-insert limit races (box files, boxes, agent tokens).
6. `register_box_source` is not idempotent.
7. Organization-wide `LIMIT` before the permission filter (composer context, open listing); bindings take the oldest revision.
8. Explanation and brief writes need write authority and an audit event.
9. Agent token counts include dead tokens.
10. No agent token expiry.
11. Box grants are written outside the share transaction.
12. `record_box_derivation` authority and digest pairing.
13. A `create_box` uploads race.
14. Python validator parity for `when` guards and duplicate transitions.

Also: dead indexes and columns, stale "0009" comments, `current_count` gated to tests, and the duplicated normalizer shared. Schema fixes go in a new migration `0012` (0011 is applied on beta).

**Canvas (`fix/review-canvas`).**
1. `swapGroup` leaves stale stacks and unite frames.
2. Shortcuts fire behind modal dialogs, including Delete.
3. The confirm and chooser host can leave the intent bar stuck.
4. Live bursts queue superseded runs.
5. No catch-up after an EventSource reconnect.
6. Space and Enter on a selected stack block panning and buttons.
7. A double decision from a live refresh.
8. Layout storage keeps the oldest entries.
9. A `placeWorkNow` duplicate race.
10. Fetch errors leave "Loading…".
11. A drag-handle listener leak.
12. Delete does nothing on folder, brief and summary cards.
13. The ledger money format.
14. Concurrent note saves.
15. "+0" stacks.
16. Failed lineage cache entries are kept.
17. Focus trap and focus return on the sheet and confirm card.

Dead code is removed. A shared `postCommand`, typing check and `announce` replace the copies.

**Infra and scripts (`fix/review-infra`).**
1. Runbook: scale to zero before the change set.
2. Runbook: the rollback path for a deregistered TaskDefinition.
3. Runbook: the change-set checklist rebuilt from `cdk diff`.
4. Runbook: one `.env` parser that strips quotes, `\r` and `export`.
5. Runbook: schema and app counts.
6. Runbook: window id and expiry inputs.
7. Runbook: the agent token kept out of argv.
8. The operator role can no longer read the ComposerModel and SlackApp secrets.
9. Display-names validation matches the service and rejects duplicates.
10. Smoke scripts: JSON-RPC errors count as failures, `store: false`, stricter loopback checks.
11. Preflight refuses secret names in the plain environment.
12. Dead allowlist entries and exports removed; constants shared.
13. Preflight records the supersession at reserve time; fixing it, or documenting it, is decided in the branch.
