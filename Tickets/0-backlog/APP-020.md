## Why

A displayed number must be exact, bounded and traceable to the authorized evidence and record snapshot that produced it. This ticket delivers: complete the typed query grammar and admission checks.

## What changes

Implement only the bounded typed operator grammar, deterministic normalization, stable ordering and type/reference/complexity validation. Exact numeric, currency/window and full-scope semantics are the following dedicated ticket.

Keep this a reviewable slice: L means approximately 3–5 focused days. Re-estimate before selection and split the ticket if it exceeds five focused days. The estimate is a planning bound, not a delivery date.

Scope excludes production deployment and real customer data; this is a synthetic qualification. Upstream framework/auth changes remain with the FormaStack team.

## Acceptance tests

- [ ] Admission and compilation support only declared projection/filter/group/sort/limit/aggregate/time-bucket/arithmetic operators and registered lookup versions.
- [ ] Schema checking rejects unknown fields, incompatible types, undeclared references and complexity excess before an engine receives a query.
- [ ] A supported query has a deterministic normalized representation and stable result order; arbitrary SQL or implementation-specific engine commands cannot enter the grammar.
