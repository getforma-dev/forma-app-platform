## Why

The platform needs a usable spatial workspace and an equivalent accessible path over the same saved work. This ticket delivers: company home, spaces, catalogs, click/slash navigation.

## What changes

Stable IDs and unique org aliases, authorized recents/suggestions/thumbnails, selection/Enter, unknown commands inert; navigation never calls the model or intercepts notes/formula text.

Keep this a reviewable slice: L means approximately 3–5 focused days. Re-estimate before selection and split the ticket if it exceeds five focused days. The estimate is a planning bound, not a delivery date.

Scope excludes production deployment and real customer data; this is a synthetic qualification. Upstream framework/auth changes remain with the FormaStack team.

## Acceptance tests

- [ ] Click and slash alias plus Enter resolve to the same stable app/space IDs; duplicate organization aliases are refused and old stable links survive rename.
- [ ] Home, recents, suggestions and thumbnails omit unauthorized private metadata before ranking or display.
- [ ] Unknown commands create nothing, ordinary navigation invokes no model, and typing in a note or formula does not trigger shell navigation.
