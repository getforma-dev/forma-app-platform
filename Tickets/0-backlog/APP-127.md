## Why

The image build lives in a Claude scratchpad, the push/preflight/change-set and operator-task scripts in the other clone's `.cache`, hard-coding both clones' paths and one window id; `$PRIV` is a flat 564-file directory in that other clone; the sealed parser path compiled into two campaigns is a scratchpad (inventory §C.1, root-cause row "Deploy steps outside Git").

## What changes

1. `ops/beta/` in Git: `build-images.sh` (candidate and clone as arguments, `set -euo pipefail`), `deploy.sh` (the `just deploy <step> <window>` steps), `run-step.sh` (`--window` required), `upload-library.py`, `env.example.sh` (the 22 variable names, no values), `verify.sh` (runbook 6.2), a shared `lib.sh`.
2. Every step that mutates AWS prints the exact command and refuses without `--approved "<Victor's words>"`; the words are appended to `$PRIV/approvals.md` before any call.
3. `$PRIV` = `<checkout>/.cache/ops/beta/` (0700/0600) with `windows/<window-id>/` and a `release.json` per deploy; `approvals.md`, `budget-ledger.json` and the private names files copied once; the old flat directory copied to `windows/_pre-adr-012/` as history (the original stays until Victor decides).
4. `just parser` builds the sealed parser into `.cache/parser-target/`; `DEFAULT_PARSER` (`dev_stand.rs`, `box_campaign.rs`) points there; `just images <candidate>`; `just deploy <step> <window>`.
5. Runbook items annotated with the recipe that performs them; the `_maintenance/clean-space.sh` special cases for the scratchpad removed.

## Acceptance tests

- [ ] Each mutating `just deploy` step refuses without `--approved` (non-zero exit, the AWS command printed, nothing called).
- [ ] With `--approved`, the words are appended to `$PRIV/approvals.md` before any AWS call (`--dry-run` shows the order without calling AWS).
- [ ] No absolute path to another checkout or a scratchpad remains in `ops/beta/` or `app/src`.
- [ ] `$PRIV` exists under the checkout with 0700 directories and 0600 files, and nothing in it is tracked by Git.
- [ ] The next beta window runs entirely through recipes and leaves one `windows/<id>/` directory (done when; needs a real window and Victor's word).

## Verification

`bash -n`, `--help`, `--dry-run` and refusal runs of every recipe (no AWS call of any kind); `git check-ignore` on `$PRIV`; the first real window is the end-to-end proof.

## Migration and rollback

The old scripts and `$PRIV` in the other clone are untouched (copied, not moved). Revert the commit to remove `ops/beta/`; `GENUI_BOX_PARSER_DIR` still overrides the parser path.
