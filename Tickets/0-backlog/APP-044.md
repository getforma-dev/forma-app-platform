## Why

The model may propose useful supported definitions but cannot expand authority, silently disclose evidence or become a runtime dependency. This ticket delivers: compose, adapt and propose changes as durable jobs.

## What changes

Retrieval/adaptation/generation labels, whole-output validation, honest abstention, bounded question/correction attempts, visible queued/running/failed state; accept creates a draft, never direct publish or partial activation.

Keep this a reviewable slice: L means approximately 3–5 focused days. Re-estimate before selection and split the ticket if it exceeds five focused days. The estimate is a planning bound, not a delivery date.

Scope excludes production deployment and real customer data; this is a synthetic qualification. Upstream framework/auth changes remain with the FormaStack team.

## Acceptance tests

- [ ] Retrieval, adaptation and genuine supported generation are labeled distinctly and persist an admitted immutable draft only after whole-output validation.
- [ ] Unsupported requests abstain with the missing capability; at most one bounded clarifying question is asked and partial model streams never activate.
- [ ] Queued/running/failed/done states survive worker restart and provider failure, and a proposal cannot publish or overwrite the current app without the governed path.
