## Why

The [APP-075 review](../../evidence/APP-075/independent-review.md) left m9 and m10 to APP-078 and named Fargate behaviours it could not observe locally; the [APP-008 acceptance review](../../evidence/APP-008/independent-acceptance-review.md) requested shared-case and reporting improvements (F2–F5). [ADR-010](../../docs/architecture/ADR-010-NOV-2-MVP-CUT.md) keeps APP-078's MVP window to the beta-critical rows and parks these here so the window stays short; they are owed before the next managed window class and before any real organization.

## What changes

1. **APP-075 m9:** add a `local_harness.py` case that uses the image's own anonymous `/run/genui` volume and no `/tmp` mount (the `check_image.py` case exists), so the harness mirrors the task filesystem.
2. **APP-075 m10:** replace the disabled-state `Fn::Select` over the empty digest parameter with `Fn.conditionIf(...)` in `infra/src/stack.ts` and keep the two-state template test, unless APP-078's stack update already proved the intrinsic is skipped (then record it).
3. **Fargate observations recorded by APP-078 as limitations:** any injected environment name the supervisor allowlist refused, the volume's ownership and the read-only root without `/tmp`, the control-plane receipt that replaces `declared_control_plane_resource_id`, and the `check_image.py --base-revision` comparison against a revision other than the tip.
4. **APP-008 F3:** add shared cases that read, under the Northstar request, the Spend Review ids that exist only in the canary organization and fresh v4 ids, asserting `Err(Error::Denied)` with identical display text, so the guessed/foreign-ID path is executed locally and on RDS.
5. **APP-008 F5:** embed a run nonce, UTC start and end and the source hashes in the native campaign report so a run cannot be mistaken for a reused transcript; F2 and F4 are recorded as superseded by exact-source CI and the current image receipt.
6. **Limits to carry:** timing side channels unassessed; `Lease::finish` reports a post-COMMIT cleanup failure as `Deadline`/`Unavailable`/`Configuration`, which write owners must treat as an ambiguous outcome (APP-013 and APP-076 record how they do).
