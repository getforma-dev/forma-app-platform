## Why

The [parser packaging review](../../evidence/APP-017/parser-packaging/independent-review.md) fixed M1–M3 and m2–m4 but left M4 (the 5e9 fuel cap exhausts at about 16,000 five-column CSV records and refuses a 10,000 × 32 XLSX, so ADR-009 D9.2/B5's bounds are unreachable) as a design decision, plus follow-ups m1, m5, m6, m7, nits n1–n6, the open SR8 signing question and a failing `parser-release.yml` run. [ADR-010](../../docs/architecture/ADR-010-NOV-2-MVP-CUT.md) places them before APP-017 Task A5 so the import bound beta members get is decided, not discovered.

## What changes

1. **M4, the fuel bound (ADR-009 amendment):** record the measurement (about 58,600 fuel per CSV cell, 87,700 per XLSX cell; practical ceiling about 85,000 CSV or 57,000 XLSX cells) and decide one of: amend D9.2/B5 to the measured bound (for example at most 50,000 aggregate cells); cut the guest's per-cell cost (a counting writer and one final serialization) and requalify; or raise fuel by ADR amendment. The chosen bound is what APP-017 Task A5's `csv_record_bound_is_cell_derived` asserts.
2. **m1:** build the parser stage without the persistent target cache (or `cargo clean` it) before any release image, so a stale guest cannot ship under a new `sources_sha256`.
3. **m5:** call `scripts/check-parser-record.py --manifest <parser-manifest.json from the exact release image>` with an authenticated `gh` from the activation preflight before the first deployment that routes imports; never pass `--github-api-fixture` there.
4. **m6:** watch the first `foundation.yml` run that builds the parser stage and raise the 20-minute timeout if needed.
5. **m7:** measure the 1.5 GiB binary line at the output cap; consider a typed decode instead of `serde_json::Value`.
6. **Nits n1–n6:** the racy `set_var` probe, the dropped closed reason on exit 1, the stdout `Vec` capacity note, `GENUI_PARSER_MANIFEST_FILE` absence fatal in `serve` once imports route, the evidence path versus the plan's `packaging/`, the shipped operator CLI form.
7. **Open items:** SR8 "signed release" remains open (attestation declined on a private repository; signing at the release step or attestation when the repository is public is the release owner's decision); `parser-release.yml` run 40963687082 failed its fixture qualification with `provenance_document_drift` (`fixtures/verify.py:71`) and must be understood before a first record is expected; plan Task A4's interface line still names only `--wasm-sha256`.
