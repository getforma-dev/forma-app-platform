## Why

The stack has no alarm, topic or AWS Budget, so nobody would know the beta was down or overspending. Changing `infra/src` would block promotion.

## What changes

A standalone CloudFormation template, `ops/monitoring/alarms.json`: an SNS email topic; alarms on load-balancer 5xx, unhealthy targets, ECS running tasks below 1 and RDS free storage; an AWS Budget alert. A Python test pins it, and Victor deploys it once.

## Acceptance tests

- [ ] The template's resources, thresholds and parameters are pinned by a test, and no `infra/src` file changes.
- [ ] After Victor deploys it, the subscription is confirmed, a test notification reaches him, and every alarm reads OK.
- [ ] The runbook names what each alarm means and the first response.

## Verification

The template test; Victor's deploy evidence.

## Migration and rollback

Deleting the standalone stack removes the alarms.
