## Why

A reviewer must control exactly what ships, while saved work retains its meaning and current access. This ticket delivers: separate saved work from personal presentation.

## What changes

Continue versus new work, fresh compatible bindings and empty record collection for reuse, persisted notes/filters/layout, explicit shared view; unsaved changes recovery on context switch and unrelated label/layout patch preserves work.

Keep this a reviewable slice: L means approximately 3–5 focused days. Re-estimate before selection and split the ticket if it exceeds five focused days. The estimate is a planning bound, not a delivery date.

Scope excludes production deployment and real customer data; this is a synthetic qualification. Upstream framework/auth changes remain with the FormaStack team.

## Acceptance tests

- [ ] Continue opens the same permitted work ID/pin/records; start new work creates fresh bindings, empty record collection and independent personal state.
- [ ] Reload restores saved notes, filters and layout; explicit shared-view saving has a stated audience distinct from personal exploratory state.
- [ ] A context switch preserves or clearly recovers unsaved edits, and a label/layout-only patch does not reset unrelated filters, records or notes.
