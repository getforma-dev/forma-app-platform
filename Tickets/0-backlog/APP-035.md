## Why

The product claim requires meaningful new apps and edits through supported primitives, with no developer rewriting a second example. This ticket delivers: isolate preview execution and draft records.

## What changes

Synthetic default; policy-enabled real read preview only under previewer's fresh source rights with same receipts/budgets and clear unreviewed label; draft mutations isolated, no copy on publish, no premature shared finalization/export.

Keep this a reviewable slice: L means approximately 3–5 focused days. Re-estimate before selection and split the ticket if it exceeds five focused days. The estimate is a planning bound, not a delivery date.

Scope excludes production deployment and real customer data; this is a synthetic qualification. Upstream framework/auth changes remain with the FormaStack team.

## Acceptance tests

- [ ] Preview defaults to synthetic evidence and trial form writes land only in a separate preview record store that publication never copies into live work.
- [ ] Policy-enabled real read preview checks the previewer’s own current source rights, admitted immutable draft, query budgets and receipts, and clearly labels the result unreviewed.
- [ ] Unauthorized source reads and promotion of preview output into finalized shared/exported decisions are denied unless revalidated under a permitted publication.
