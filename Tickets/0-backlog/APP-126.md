## Why

A full check is eight command lines across four toolchains with no single entry point; 34 ignored campaigns are known only from CI YAML and ticket logs; the editor workspace is a single folder with no tasks (inventory §B.4, §B.5, §D).

## What changes

1. `justfile` (just 1.59.0, pinned in `tools.versions`): `setup`, `doctor`, `dev` (wrapping `app/scripts/dev_stand.sh` / `fresh_stand.sh` until step 4), `restart`, `check`, `ci`, `campaigns`, `campaign <name>`, `clean`; every recipe a thin call into `scripts/dev/*.sh`.
2. `scripts/dev/campaigns.tsv`: the catalog of every `#[ignore]` test by short name, real test path, report variable and CI status; `campaigns.sh verify` compares it with `cargo test --lib -- --list --ignored`.
3. `forma-pitch-mvp.code-workspace` (roots, rust-analyzer settings, excludes, tasks bound to recipes, extension recommendations).
4. `.claude/launch.json`: the persona URL entries kept (plus Alex on :4010), and entries that run `just dev` / `just dev clean`.

## Acceptance tests

- [ ] `just --list` shows every recipe with a one-line description.
- [ ] `just check` runs the CI-fast set in one command and reports each failure by name.
- [ ] `just campaigns` lists all 34 ignored tests with their real paths and CI status, and `campaigns.sh verify` agrees with cargo's list.
- [ ] `just campaign <name>` runs exactly one campaign with its report under `.cache/reports/`.

## Verification

`just --list`, `just check`, `just campaigns`, `scripts/dev/campaigns.sh verify`; results in the log.

## Migration and rollback

Additive: the old scripts keep working. Revert the commit to remove the front door.
