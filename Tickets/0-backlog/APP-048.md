## Why

Continuing shared work and starting independent work require separate grants, current source access and explicit data audiences. This ticket delivers: separate app, work, source, record and export grants.

## What changes

Implement independent grants and explicit audiences for app sharing, saved-work continuation and export. Links carry identifiers, personal state is not implicitly shared, and independent reuse creates fresh data bindings. Source-dependent derived-content enforcement follows separately.

Keep this a reviewable slice: L means approximately 3–5 focused days. Re-estimate before selection and split the ticket if it exceeds five focused days. The estimate is a planning bound, not a delivery date.

Scope excludes production deployment and real customer data; this is a synthetic qualification. Upstream framework/auth changes remain with the FormaStack team.

## Acceptance tests

- [ ] Granting app discovery/run, saved-work access, source read, record write and export are separate explicit operations with independently tested permission checks.
- [ ] A copied link carries only an identifier and opens nothing for an ungranted principal; private notes/personal layouts do not become shared by app sharing.
- [ ] Jordan can continue shared work only with the required grants, while starting independent work creates a fresh binding and record collection.
