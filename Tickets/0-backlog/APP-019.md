## Why

The platform needs a usable spatial workspace and an equivalent accessible path over the same saved work. This ticket delivers: implement accessible drop/upload source cards.

## What changes

Limits before upload, progress/cancel, inspection/failure/retry states and keyboard control equivalent to drop; neither path bypasses mapping/admission; meaningful initial placement.

Keep this a reviewable slice: L means approximately 3–5 focused days. Re-estimate before selection and split the ticket if it exceeds five focused days. The estimate is a planning bound, not a delivery date.

Scope excludes production deployment and real customer data; this is a synthetic qualification. Upstream framework/auth changes remain with the FormaStack team.

## Acceptance tests

- [ ] Dropping a supported file and using keyboard Upload each create the same inspected source-card workflow with restrictions visible before transfer.
- [ ] Progress, cancellation, worksheet selection and actionable failure/retry are reachable without a pointer and cannot bypass mapping confirmation.
- [ ] A new source card is placed without obscuring current work and remains identifiable across inspection/reload, with usable initial arrangement and intentional empty-canvas option.
