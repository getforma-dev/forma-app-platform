## Why

Imported evidence is usable only when its interpretation, limits and historical identity are explicit and reproducible. This ticket delivers: store original and normalized immutable revisions.

## What changes

Tenant-scoped storage/key adapters, original digest, parser/mapping revisions, atomic object-before-row commit, tombstones and cache invalidation; missing/deleted sources never silently rebind.

Keep this a reviewable slice: L means approximately 3–5 focused days. Re-estimate before selection and split the ticket if it exceeds five focused days. The estimate is a planning bound, not a delivery date.

Scope excludes production deployment and real customer data; this is a synthetic qualification. Upstream framework/auth changes remain with the FormaStack team.

## Acceptance tests

- [ ] An uploaded original and normalized revision are tenant-scoped, digest-addressed and linked with parser/mapping versions only after durable object write succeeds.
- [ ] Failed object write leaves no usable revision; identical content does not permit foreign-tenant reads or substitute another user’s authority.
- [ ] Delete or lose a source and reopen work: preserve the historical identity/tombstone, invalidate derived cache references and never silently bind a newer revision.
