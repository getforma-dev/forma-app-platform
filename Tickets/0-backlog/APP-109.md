## Why

Victor, 2026-10-30: "the ad hoc ones like clock and calculator and weather, add a note so one can do /note real quick and save a note as a card."

## What changes

`/note <text>` (or `/note` for an empty one) places a note card: a title line and a short body (plain text, at most 2,000 characters, rendered as text, never markup). Notes are saved as records of a per-member "Notes" collection through the audited command route (typed, idempotent), so they persist across browsers and can later be shared or dropped into a box (APP-108). Edit in place on the card (save on blur), delete back to the library. Listed in the library pane under "Utilities → Notes" and in `/` autocomplete.

## Acceptance tests

- [x] `/note Call the auditor Friday` places a note card that survives a reload and another browser.
- [x] Markup or script in a note renders as plain text.
- [x] Notes are private to the member unless shared.

## Verification

Unit tests; one browser walk with a screenshot.

## Migration and rollback

No migration if notes are records of an existing collection kind; otherwise additive.
