## Why

Victor, 2026-10-31: "those numbers look crazy, can't we call it northstar? like /t/northstar … while navigating the canvas we have that at the end of every route?"

ADR-006 chose random 26-character handles so nobody can tell which companies use Forma. Most B2B products use readable workspace names instead (`acme.slack.com`, `acme.atlassian.net`, `/acme` paths on GitHub, Notion and Linear) and accept that a workspace's existence can be learned. They limit the risk with uniform responses, rate limits, and nothing shown before sign-in.

## What changes

1. **Sign-in alias (done, 2026-10-31).**
   - `/signin/northstar` routes exactly as the random handle does. The map comes from deployment configuration: `GENUI_SIGNIN_ALIASES_JSON`, set at synth from the private `signinAliasesFile`.
   - An unknown name gives the same neutral page as an unknown handle.
   - The random handle keeps working, so an organization that wants to stay unlisted simply has no alias.
2. **Admin-managed aliases.** Aliases move into the database (operator or admin command, audited). The uniform response and rate limits on `/signin/*` stay.
3. **Organization in every URL.** For example `/northstar/canvas` and `/northstar/w/{app}/{work}`, for members of several organizations and for shareable links.
   - The organization still comes only from the verified session.
   - A URL naming a different organization than the session's gets the uniform 404, or a prompt to switch organization once multi-organization membership exists.
   - All routes, the canvas links, Slack and MCP links, and the event stream change accordingly.
4. **Subdomains (enterprise).** `northstar.getforma.dev` needs:
   - wildcard DNS and a certificate;
   - an ALB host rule;
   - fAuth return-URL registration per organization;
   - cookie scoping per host (`__Host-` cookies are already host-only).

## Acceptance tests

- [ ] `/signin/northstar` starts the same sign-in flow as the random handle. An unknown alias and an unknown handle return byte-identical neutral pages. A name 26 characters long, or with characters outside `a-z0-9-`, is never an alias.
- [ ] `/northstar/canvas` serves the canvas for a Northstar member. A Canary member gets the uniform 404 there. Old URLs redirect.
- [ ] Subdomain sign-in works end to end with fAuth, and cookies never leak across organization hosts.

## Verification

Unit tests for alias parsing (done); a session campaign covering prefixed routes; a browser walk.

## Migration and rollback

The alias needs none (configuration). Admin-managed aliases add a table. Prefixed routes keep the old paths as redirects for one release.
