## Why

The documented invitation path (`ops/beta/run-step.sh`) is fenced since deploy state moved to the promotion bucket, so nobody can be invited through a reviewed path.

## What changes

A new `ops/promotion/admission.py`, following the operator module pattern:
- `issue --count N --notes-file`, which always clears the one-shot secret and writes the codes to a private file.
- `list` and `revoke`.
- `grant-admin`.
- `set-org-name`, if the operator supports it.
- `delete-uploads`, which deletes every S3 version of one member's files.
- `restart --announced`.

It adds `--note` on `admission_operator.py issue` and trial-organization overrides. One restart serves every invite issued before it.

## Acceptance tests

- [ ] Every command's requests and refusals are covered by fake-AWS tests: wrong account, wrong organization, stale state, a secret not cleared, more than 128 capabilities, a missing task definition.
- [ ] `issue` never leaves the invitation-input secret populated, even when the task fails, and codes exist only in the private file.
- [ ] The runbook (APP-188) names each command with its expected output. An independent Tier A review finds no blocker.
