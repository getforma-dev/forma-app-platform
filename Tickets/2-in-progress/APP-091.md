## Why

The backbone (invite, verified sign-in, governed query with receipt, explicit command) is live but does not show the product. Three prototypes beside this repository do: Forma GenUI Runtime (the reusable canvas), Forma Generative UI (intent planner and a vector index of published modules) and Forma Vector Studio (Claude composes reusable modules). [ADR-011](../../docs/architecture/ADR-011-NOV-2-EMERGENCY-PIVOT.md) decides to join them with the backbone in a clone so the platform's board and evidence stay intact.

## What changes

1. Create the clone `FormaBuiltApps/forma-pitch-mvp`, branch `pivot/pitch-mvp`, from `phase-one-spikes` at `21199f4`, pushed.
2. Write the integration architecture in the clone: the canvas runtime mounts as an island on the signed-in workspace; the planner and the module index run server-side under the session's tenant scope; Vector Studio's composition path produces modules only as typed definitions that pass `app/src/admission/`; canvas data goes through the governed query and command paths; the model key comes from a secret.
3. Name every shortcut taken for November 2 (canvas islands beyond APP-003's qualification, the model call before APP-043, relaxed review depth) so APP-097 can pay or carry each one.
4. Define the seams that APP-092–096 build on, and the order they land in the clone.
