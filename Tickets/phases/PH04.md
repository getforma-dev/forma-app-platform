# PH04: Complete two-app demonstration

Team: GenUI. Progress: **planned**. Exit gate: **pending**.

Predecessor phases: [PH03](PH03.md)

## Outcome

Northstar and Spend Review complete the designed shared-work, independent-reuse and recovery journey on one unchanged build.

## Entry

PH03 supports genuine app creation, governed publication and bounded AI; the existing dependency graph controls individual starts.

## Deliverables

- Separate sharing grants, derived-data redaction, end-to-end revocation, authorized export and colleague continuation/reuse (APP-048–052).
- Actual synthetic restore/deletion/quota recovery before demo signoff (APP-053).
- Full Northstar and Spend Review runs, adversarial/accessibility suite, guarded reset and six-act rehearsal evidence (APP-054–057).

## Exit gate

All phase tickets must be Done, predecessor phase gates must pass, and the following evidence must be accepted. Ticket completion alone does not complete the phase. Follow the [quality gates](../../docs/planning/QUALITY-GATES.md) for checks, release trials and evidence standards.

- [ ] Demo control applicability is recorded: platform SR1/2/4–7/10–13 hold; demo §10.7 substitutes typed in-process principals for SR3 and pinned image/per-build tests for SR8, and accepts SR9 reduction under demo AR1. Demo-SR1–SR6 and the §11.1 pre/post-take protocol pass (APP-056/057); full platform controls remain PH05 work.
- [ ] All Northstar scenarios S01–S07 pass with exact source/record receipts and a real user-created second app. No per-example source patch or deployment is used (APP-054/055/057).
- [ ] Sharing, cached/derived responses, export and delayed jobs obey current permissions; revocation and command races pass at the reconciled end-to-end bound (APP-048–052).
- [ ] Restore uses actual persisted backups, not fixture reseeding; deletion ledger, restart, quotas and isolation continue to hold. S06 adversarial and accessibility checks pass (APP-053/056). Insert-only audit chains are anchored to Object Lock every 15 minutes and restored chains match retained anchors (APP-053; demo M13–M14).
- [ ] Six-act release rehearsal records one build, both app digests, model/source pins, outcomes, failures and manual intervention. Reset requires rehearsal mode plus a restricted role, preserves audit/sessions and is absent in real-data mode (APP-057). The sanitized packet has no credentials or retained headers, every shown value matches its captured receipt, and its manifest digest is audited and anchored before delivery (demo M31).
