# PH05: Managed pilot controls

Team: GenUI. Progress: **planned**. Exit gate: **pending**.

Predecessor phases: [PH04](PH04.md)

## Outcome

The hosted platform has controlled deployment, service identities, audit, support access and data lifecycle mechanisms.

## Entry

PH04 synthetic demo evidence is accepted. Confirm pilot scope and identity prerequisites in APP-058; no live-data entry is granted here.

## Deliverables

- Named pilot workflow/data/operator/budget/region/disclosure plan and FormaStack key-custody receipt (APP-058).
- Role-separated infrastructure and service identity, reproducible signed builds and reversible rollout (APP-059–061).
- Append-only audit/anchors, constrained support, retention/crypto-shredding, organization deletion and administration (APP-062–066).

- [ ] FORMA-248 key custody/rotation/outage evidence is accepted, and the pilot scope/operator/budget/data decisions are recorded. APP-058 does not approve live customer data.
- [ ] Role and service-token negative tests pass; unsigned/mismatched release artifacts are refused. SBOM/provenance and exact deployable digest are retained (APP-059–061).
- [ ] Run previous/current API compatibility, migration upgrade → downgrade → upgrade, callee-first canary and rollback trials in the intended isolated environment; record actual candidate identities and stop conditions (APP-061).
- [ ] Audit-chain/anchor checks, just-in-time support/breakglass, destructive-action governance with the recorded platform AR1 fallback where applicable, retention and the 24-hour organization-deletion hold pass (APP-062–066).
