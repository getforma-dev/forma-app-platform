# PH02: Working data and workspace

Team: GenUI. Progress: **planned**. Exit gate: **pending**.

Predecessor phases: [PH01](PH01.md)

## Outcome

People import real files, get correct traceable results, use accessible views/forms, and return to saved work.

## Entry

PH01 is accepted for integrated delivery. Individual storage/import or UI work can start earlier once its own prerequisites are Done.

## Deliverables

- Durable bounded jobs, immutable source storage, CSV/XLSX processing and confirmed interpretation (APP-015–019).
- Typed queries, exact arithmetic/domain operators, reproducible receipts, resource admission and linked filter epochs (APP-020–025).
- Company navigation, canvas interactions, trusted renderers, accessibility, general forms and distinct new/continued work (APP-026–031, APP-081).

## Exit gate

All phase tickets must be Done, predecessor phase gates must pass, and the following evidence must be accepted. Ticket completion alone does not complete the phase. Follow the [quality gates](../../docs/planning/QUALITY-GATES.md) for checks, release trials and evidence standards.

- [ ] Both drop and keyboard upload exercise actual CSV/XLSX parsing, mapping confirmation and refusal paths; archive-wide memory/time/expansion limits and provenance are verified (APP-015–019).
- [ ] Northstar totals are 1,140,000 bytes, 900,000 unmatched and 114,000 bytes/minute; Spend Review totals are 64,000 cents with a 45,000-cent queue. Tests cover windows, units, currencies, pagination and receipt/record snapshot identity (APP-020–025).
- [ ] Pan/zoom/move/resize/group/fit, focus navigation and forms work through the same model. Component state accessibility checks plus keyboard and screen-reader evidence pass (APP-027–030, APP-081).
- [ ] Reload, independent new work, original-node adoption, form retry/conflict and late cross-context responses preserve correct data and authority (APP-025–031, APP-081).

Gate evidence:

- Pending; no phase acceptance claimed.
