# PH09: Composed app experience

Team: GenUI. Progress: **active**. Exit gate: **pending**.

Predecessor phases: None — start here.

## Outcome

Cards behave as components of one coherent, authorized web app, with a consistent embedded and standalone experience and real record-backed behavior.

## Entry

ADR-015 is accepted. APP-139/140 genuine-trial continuation stays first; individual ticket dependencies govern selection. This follow-through neither expands the November 2 cut nor waits for unrelated historical PH08 leftovers.

## Deliverables

- A backward-compatible admitted app presentation contract and trusted responsive shell (APP-155).
- Typed component actions with builder target selection and preserved command/draft semantics; persisted bounded themes (APP-156/157).
- Admitted record components and scoped filters, bounded exact record calculations and receipts (APP-158/159).
- A normally created reference app with actual saved records, cross-presentation interaction, permission and accessibility evidence (APP-160).
- Measured future idle/wake options, an architecture decision and follow-up ownership; no automatic infrastructure change (APP-161).
- Whole-app canvas views and Apps/Widgets/Cards Library (APP-168); explicit follow-ups for durable artifact kind/legacy cleanup (APP-169), published visibility (APP-170) and desktop icon exploration (APP-171).

## Exit gate

All phase tickets must be Done, predecessor phase gates must pass, and the following evidence must be accepted. Ticket completion alone does not complete the phase. Follow the [quality gates](../../docs/planning/QUALITY-GATES.md) for checks, release trials and evidence standards.

- [ ] All APP-155–161 tickets are Done with their own required evidence; visual references and planning checks do not pass runtime acceptance.
- [ ] The same exact saved work is qualified across embedded, standalone member and guest presentations; commands remain explicit and sharing retains ADR-014 authority and five-second visibility lease.
- [ ] Record metrics and charts are recomputable from admitted real snapshots with exact arithmetic, declared scope and receipts; no fake or page-truncated totals.
- [ ] Independent review accepts compatibility, isolation, keyboard/mobile behavior, recovery and honest availability states. APP-161 ends at an evidence-backed decision; any implementation is separately ticketed.
