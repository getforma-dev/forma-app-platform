# Input

Everything the task was given, as given. Nothing in this folder is edited by the factory.

- `brief.md`: the assignment text, pasted verbatim, including evaluation criteria, page limits, deadline, format.
- `context/`: any files that came with it (PDFs, data samples, diagrams, links).
- `constraints.md`: things not written in the brief but known (expected stack, time budget, who reviews).
